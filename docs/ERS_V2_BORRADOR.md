# ERS versión 2 — borrador

> Borrador generado desde el caso Forma A y el código actual. No reemplaza un ERS V1 firmado por el equipo si existía en otra entrega.

## Objetivo

Sistema web frontend para publicar servicios veterinarios, solicitar citas y administrar catálogo y solicitudes en modo simulado.

## Actores

Administrador, recepcionista, veterinario, técnico, dueño de mascota.

## Requisitos funcionales principales

- RF-01 Catálogo de 31 servicios con búsqueda y filtros.
- RF-02 Detalle de servicio.
- RF-03 Solicitud de cita con estados.
- RF-04 Consulta de mis citas por correo.
- RF-05 Recepción confirma o propone horario.
- RF-06 Admin CRUD servicios y gestión de citas.
- RF-07 Login simulado por rol.
- RF-08 Blog y contenidos institucionales.

## Requisitos no funcionales

- Responsive Bootstrap.
- Código en JavaScript con Vitest.
- Persistencia localStorage.

## Fuera de alcance

Backend Spring, MySQL, pagos en línea, historial clínico completo.
